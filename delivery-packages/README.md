# Private product downloads

Keep the ZIPs out of Git and the public website. Upload the matching ZIP to each product in your payment provider's private file-delivery area; the provider then emails its download link after a completed payment.

Current products: `skin-studio.zip`, `table-no-01.zip`, `form-studio.zip`, `motion-club.zip` and `still-house.zip`.

After editing a product, rebuild its ZIP from the matching local source folder under `../Nueva carpeta/` (for example, `../Nueva carpeta/table-no-01/`). The ignored ZIP files are not included in Git or the public GitHub Pages site.
